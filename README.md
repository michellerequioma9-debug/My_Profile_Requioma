# Michelle Requioma — Infrastructure Services Profile

GitHub Pages-ready personal profile website for BSIT 3rd Year.

## Files
- `index.html` — main profile website
- `resume.html` — HTML resume page (not a PDF)
- `style.css` — all website and resume styling
- `profile.png` — profile photo
- `wallpaper.jpg` — website background
- `linux-unhatched.pdf` — certificate
- `computer-hardware-basics.pdf` — certificate
- `networking-devices-initial-configuration.pdf` — certificate

## GitHub Pages
Upload the files themselves to the repository root. Do **not** upload only the ZIP file.
Then go to Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
The site URL should be:
`https://michellerequioma9-debug.github.io/My_Profile/`

The Resume button opens `resume.html`. It is a real HTML page, so it will not depend on a resume PDF. The Print / Save as PDF button is optional if a PDF copy is needed later.
